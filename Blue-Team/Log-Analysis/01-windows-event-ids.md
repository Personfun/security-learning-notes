# Windows 日志分析与核心事件 ID

Windows 事件日志是蓝队应急响应和威胁狩猎的核心数据来源。本笔记记录高频安全事件 ID，以及与红队攻击动作的对应关系。

## 1. 日志开启与查看

### 开启审核策略
默认情况下，Windows 不记录所有事件。需在本地安全策略中开启：
```cmd
secpol.msc
```
依次展开：本地策略 → 审核策略，建议开启：
- 审核登录事件（成功和失败）
- 审核账户管理（成功和失败）
- 审核进程跟踪（成功）
- 审核策略更改（成功和失败）

### 常用查看方式
- **事件查看器**：`eventvwr.msc`
- **命令行**：`wevtutil qe Security /f:text /c:100`
- **PowerShell**：`Get-WinEvent -LogName Security | Where-Object {$_.Id -eq 4624}`

## 2. 核心事件 ID 速查表

### 2.1 登录与认证

| 事件 ID | 含义 | 安全意义 |
|:---|:---|:---|
| **4624** | 登录成功 | 关注**登录类型**：2(交互)、3(网络)、10(RDP) |
| **4625** | 登录失败 | 大量出现说明**密码爆破** |
| **4634** | 注销成功 | 辅助判断会话生命周期 |
| **4647** | 用户发起注销 | 正常退出 |
| **4672** | 分配了特殊权限 | 管理员登录时出现，关注非预期的特权分配 |
| **4776** | NTLM 身份验证 | 关注 PTH（Pass The Hash）攻击 |
| **4768** | 请求 Kerberos TGT | 关注 AS-REP Roasting（大量 RC4 加密） |
| **4769** | 请求 Kerberos TGS | 关注 Kerberoasting（大量 RC4 加密） |

### 2.2 进程与执行

| 事件 ID | 含义 | 安全意义 |
|:---|:---|:---|
| **4688** | 创建了新进程 | 需配合命令行记录，关注 `cmd.exe /c`、`powershell.exe` |
| **4104** | PowerShell 脚本块日志 | 发现无文件攻击、混淆脚本 |
| **4697** | 安装了服务 | 关注 PsExec（PSEXESVC）、Cobalt Strike 服务 |
| **7045** | 系统安装了新服务 | 与 4697 类似，重点关注服务名和二进制路径 |

### 2.3 账户与组管理

| 事件 ID | 含义 | 安全意义 |
|:---|:---|:---|
| **4720** | 创建了用户账户 | 关注隐藏用户（末尾带 `$`） |
| **4726** | 删除了用户账户 | 攻击者清理痕迹 |
| **4732** | 将成员添加到本地组 | 关注加入 `Administrators` 组的操作 |
| **4738** | 修改了用户账户 | 修改权限或属性 |

### 2.4 持久化与防御规避

| 事件 ID | 含义 | 安全意义 |
|:---|:---|:---|
| **4698** | 创建了计划任务 | 关注异常的计划任务名称和触发时间 |
| **1102** | 日志被清除 | **高危告警**，攻击者掩盖痕迹 |
| **104** | 日志被清除（系统日志） | 同上，重点关注 |
| **4657** | 注册表值被修改 | 关注 `Run` 键、IFEO（粘滞键后门） |

## 3. 红蓝对照：攻击动作与事件 ID 对应表

| 红队攻击动作 | 触发的核心事件 ID |
|:---|:---|
| 密码爆破 | 4625（大量失败）、4624（最终成功） |
| PsExec 横向移动 | 7045（服务安装）、4624 类型3 |
| 创建隐藏用户 | 4720、4732 |
| 计划任务后门 | 4698 |
| 粘滞键后门（IFEO） | 4657（注册表修改） |
| DCSync | 4662（目录服务访问） |
| Kerberoasting | 4769（大量 RC4 TGS 请求） |
| 日志清除 | 1102 |

## 4. 实战查询示例

### PowerShell 查询登录失败
```powershell
Get-WinEvent -FilterHashtable @{LogName='Security'; ID=4625} | Select-Object TimeCreated, Message -First 10
```

### Splunk SPL 查询
```spl
index=windows EventCode=4720 OR EventCode=4732
| table _time, EventCode, user, Message
```

## 5. 面试高频问题

**Q1：如何检测密码爆破？**
A：关注事件 ID 4625（登录失败）。如果在短时间内同一账户或同一 IP 出现大量 4625，随后出现 4624（登录成功），基本可以断定是密码爆破攻击。

**Q2：如何检测 PsExec 横向移动？**
A：关注事件 ID 7045（安装了新服务），服务名通常为 `PSEXESVC`，二进制路径为 `C:\Windows\PSEXESVC.exe`。同时结合事件 ID 4624（登录类型 3，网络登录）。

**Q3：如何检测隐藏用户？**
A：关注事件 ID 4720（创建了用户账户），如果用户名末尾带有 `$`（如 `admin$`），或使用了与系统账号相似的名称（如 `adm1n`），需要警惕。同时结合 4732 查看是否被加入了管理员组。

**Q4：如何检测 DCSync 攻击？**
A：关注事件 ID 4662（目录服务访问）。如果一台非域控机器发起了具有“复制目录更改”权限的请求，说明存在 DCSync 行为。这是高危告警。

**Q5：攻击者如何清除痕迹？你会怎么发现？**
A：攻击者通常会执行 `wevtutil cl Security` 清除日志，这会触发事件 ID 1102（日志被清除）。蓝队应重点监控 1102，并配置日志集中收集（SIEM），防止本地日志被清除后无法溯源。
