# WAF、IDS 与 HIDS 学习笔记

在安全防御体系中，WAF、IDS/IPS、HIDS 构成了不同层级的防护网。本文记录这三类设备的核心原理、部署模式以及红蓝对抗中的绕过与检测思路。

## 一、WAF (Web 应用防火墙)

### 1. 原理
WAF 专注于 HTTP/HTTPS 流量，通过解析 HTTP 请求，匹配规则库或进行语义分析，拦截 SQL 注入、XSS、文件包含、命令注入等 Web 攻击。

### 2. 分类与部署模式

| 类型 | 部署方式 | 特点 |
|:---|:---|:---|
| **云 WAF** | 通过 DNS 解析将流量牵引到云端 | 部署简单，按量付费，适合中小型企业 |
| **硬件 WAF** | 串联在 Web 服务器前（反向代理或透明模式） | 性能高，延迟低，适合大型企业 |
| **软件 WAF** | 安装在服务器上（如 ModSecurity） | 灵活性高，成本低，但占用服务器资源 |
| **插件 WAF** | 集成在 Web 框架中（如 Java Filter） | 与应用强绑定，无法防护框架外的漏洞 |

### 3. 常见绕过手法
- **大小写混合**：`SeLeCt`、`UnIoN`
- **内联注释**：`/*!SELECT*/`
- **等价替换**：`OR 1=1` 替换为 `OR 2>1`
- **编码绕过**：URL 编码、Unicode 编码、十六进制编码
- **分块传输**：Chunked Transfer 绕过内容检测
- **参数污染**：`?id=1&id=2' UNION SELECT...`

### 4. 面试重点
WAF 不是万能的，它是**基于规则或语义的辅助防御**。真正的安全必须依赖代码层的参数化查询和白名单校验。

## 二、IDS / IPS (入侵检测与防御系统)

### 1. 原理
- **IDS (入侵检测系统)**：旁路部署，只监听流量，发现异常时**产生告警**，但不阻断。
- **IPS (入侵防御系统)**：串联部署，发现异常时**直接阻断**流量。

### 2. 检测技术
- **特征检测（Signature-based）**：匹配已知攻击的特征库（如 Snort 规则）。准确率高，但无法检测 0day。
- **异常检测（Anomaly-based）**：建立正常流量基线，偏离基线的行为即告警。能检测未知威胁，但误报率较高。

### 3. 常见规避手法
- **流量碎片化**：将攻击载荷拆分到多个 TCP 包中，绕过特征匹配。
- **流量加密**：使用 HTTPS 或 SSH 隧道，IDS 无法解密内容。
- **慢速攻击**：如 Slowloris，通过慢速发送请求耗尽服务器资源，IDS 难以察觉。

## 三、HIDS (主机入侵检测系统)

### 1. 原理
HIDS 在主机上安装 Agent，监控文件完整性（FIM）、进程创建、网络连接、系统日志、注册表等，发现异常行为时告警。

### 2. 核心功能
- **文件完整性监控 (FIM)**：监控核心文件（如 `/etc/passwd`、Web 目录）是否被修改。
- **进程监控**：记录进程的完整命令行、父进程关系（类似 Sysmon）。
- **网络监控**：记录主机的网络连接（类似 `netstat`）。
- **日志采集**：将系统日志转发到 SIEM。

### 3. 代表工具
- **Wazuh**：开源 HIDS，功能全面，支持 FIM、漏洞检测、日志分析。
- **Osquery**：将操作系统视为数据库，使用 SQL 查询系统状态。
- **阿里云安全中心 / 腾讯云主机安全**：云原生 HIDS。

### 4. 面试重点
HIDS 是发现“无文件攻击”、“WebShell 落地”、“权限维持”的关键。它弥补了 WAF 和 IDS 只看网络流量的盲区，直接监控主机内部的行为。

## 四、红蓝对抗中的协同

| 设备 | 红队视角（绕过） | 蓝队视角（检测与防御） |
|:---|:---|:---|
| **WAF** | 编码、分块传输、参数污染 | 部署语义分析规则，定期更新规则库 |
| **IDS/IPS** | 流量加密、碎片化、慢速攻击 | 结合威胁情报，配置异常流量告警 |
| **HIDS** | 免杀、无文件落地、白利用 | 监控文件完整性、异常进程、注册表 |

## 五、面试高频问题

**Q1：WAF 和 IPS 的区别是什么？**
A：WAF 专注于 Web 应用层（HTTP/HTTPS），拦截 SQL 注入、XSS 等 Web 攻击；IPS 是网络层设备，基于流量特征检测入侵行为，覆盖面更广，但不深入解析 Web 应用逻辑。WAF 可以视为 IPS 在 Web 领域的细分。

**Q2：HIDS 如何检测 WebShell？**
A：HIDS 可以通过文件完整性监控（FIM）发现 Web 目录中新增的 `.php` 文件；通过进程监控发现 Web 进程（如 `php-fpm`）启动 `cmd.exe` 或 `bash` 的异常行为；通过日志分析发现 Web 访问日志中的异常请求。

**Q3：如果 WAF 被绕过了，你还有什么补救措施？**
A：WAF 是辅助防御，不能替代代码安全。如果被绕过，应立即排查代码层漏洞（参数化查询、白名单校验），同时通过 HIDS 和 SIEM 进行主机层和流量层的告警与阻断，并排查 Webshell 落地。
