# 应急响应报告编写指南

## 一、报告目的

记录安全事件全过程，明确问题、处置和修复建议。

## 二、报告结构

```
封面
事件概述
排查过程
发现的问题
处置措施
修复建议
结论
```

## 三、事件概述

需要写清：

- 发现时间
- 影响主机
- 事件类型
- 影响范围

示例：

```
2026年9月2日，发现 Windows 主机 DESKTOP-6O9K55F 存在异常账户和计划任务，判断为攻击者留下的后门。
```

## 四、排查过程

按实际排查顺序写：

```
用户账户排查
计划任务排查
服务排查
启动项排查
网络连接排查
进程排查
```

## 五、发现的问题

用表格列出：

| 序号 | 类型 | 详情 |
| ---- | ---- | ---- |
| 1 | 隐藏账户 | wmihacker |
| 2 | 计划任务 | SystemUpdateTask |
| 3 | 启动项 | Update |

## 六、处置措施

写清每项处置：

```
删除后门账户
删除恶意计划任务
删除恶意启动项
```

## 七、修复建议

- 修改管理员密码
- 检查安全策略
- 开启登录审计
- 加强监控

## 八、结论

总结事件影响和后续动作。
