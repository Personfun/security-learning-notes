# 等保 2.0 基础与流程

网络安全等级保护（简称“等保”）是我国网络安全领域的基本国策和基本制度。等保 2.0 是国家在 2019 年正式发布的新标准，将“信息安全”升级为“网络安全”，并扩展了云计算、移动互联、物联网、工控安全等新领域的合规要求。

## 1. 五个安全保护等级

| 等级 | 名称 | 适用对象 | 监管要求 |
|:---|:---|:---|:---|
| **第一级** | 用户自主保护级 | 一般企业内网、小型网站 | 自主定级、自主保护，无需备案和测评 |
| **第二级** | 系统审计保护级 | 一般政府网站、中小企业系统 | 需备案，建议测评（非强制） |
| **第三级** | 安全标记保护级 | 政府、金融、能源、大型企业核心系统 | **强制备案、每年至少测评一次** |
| **第四级** | 结构化保护级 | 国家重要领域（如银行核心系统、电网） | 强制备案、每半年至少测评一次 |
| **第五级** | 访问验证保护级 | 国家极端重要系统（如国防） | 特殊监管，一般企业不涉及 |

## 2. 等保 2.0 的五大工作流程

1. **定级**：根据业务系统受破坏后的影响范围（公民、社会、国家），确定系统等级（一到五级）。
2. **备案**：携带定级报告等材料，到属地公安机关网安部门进行备案（二级及以上需备案）。
3. **建设整改**：根据等保标准，对系统进行安全加固（如部署 WAF、堡垒机、日志审计等）。
4. **等级测评**：由具备资质的测评机构进行测评，出具测评报告。三级系统每年至少测评一次。
5. **监督检查**：公安机关定期对备案系统进行监督检查。

## 3. 测评内容：十项通用要求（口诀记忆）

等保 2.0 的测评内容可以概括为“十项要求”：
**物理、网络、边界、计算、中心、制度、机构、人员、建设、运维**。

具体内容如下：
1. **安全物理环境**：机房的门禁、防火、防水、防盗。
2. **安全通信网络**：网络架构、通信传输加密（如 VPN）。
3. **安全区域边界**：防火墙、WAF、IDS/IPS 等边界防护设备。
4. **安全计算环境**：服务器、数据库、终端的安全配置、身份鉴别、访问控制。
5. **安全管理中心**：日志审计、堡垒机、集中管控。
6. **安全管理制度**：安全策略、管理制度、操作规程。
7. **安全管理机构**：岗位设置、人员配备、授权审批。
8. **安全管理人员**：人员录用、离岗、考核、培训。
9. **安全建设管理**：系统定级、安全方案设计、产品采购。
10. **安全运维管理**：环境管理、资产管理、漏洞管理、备份恢复。

## 4. 三级等保常见的核心设备

| 设备 | 作用 |
|:---|:---|
| **防火墙** | 网络边界访问控制 |
| **WAF** | Web 应用防护，拦截 SQL 注入、XSS |
| **IPS** | 入侵防御，阻断恶意流量 |
| **堡垒机** | 运维审计，集中管理服务器登录 |
| **日志审计系统** | 集中收集和审计全网日志 |
| **数据库审计** | 监控数据库操作，防止数据泄露 |
| **漏洞扫描系统** | 定期扫描系统漏洞 |
| **态势感知平台** | 全局安全态势监控和告警 |

## 5. 面试高频问题

**Q1：什么是等保？为什么要做等保？**
A：等保是国家网络安全等级保护制度，要求根据信息系统的重要程度进行分级保护。做等保不仅是为了满足国家法律法规的合规要求，也是为了通过系统化的安全建设，降低被攻击的风险。

**Q2：三级等保和二级等保最大的区别是什么？**
A：三级等保要求更严格：强制备案、每年至少测评一次，且在“安全计算环境”和“安全管理中心”上有更细致的要求。三级系统通常需要部署堡垒机、日志审计、数据库审计、WAF 等设备。

**Q3：等保测评的流程是什么？**
A：定级 → 备案 → 建设整改 → 等级测评 → 监督检查。其中，定级是根据业务受破坏后的影响范围来确定，测评则由具备资质的第三方测评机构进行。

**Q4：如果客户系统要过三级等保，但预算有限，你会建议优先买什么设备？**
A：优先满足“必选项”：防火墙（边界）、WAF（Web防护）、堡垒机（运维审计）、日志审计（集中日志）。这些是三级等保测评的“硬指标”，缺失会直接影响测评结果。
