# 威胁狩猎基础（Threat Hunting）

威胁狩猎是一种主动的安全防御手段。传统的安全运营（SOC）是“被动等待告警”，而威胁狩猎是主动假设“网络已经被入侵”，通过分析海量日志和终端数据，寻找隐藏的攻击者痕迹。

## 1. 核心思维：假设已被入侵

威胁狩猎的核心理念是基于“假设已被入侵（Assume Breach）”，不再依赖已知的杀毒软件或 WAF 告警，而是通过以下方式主动寻找威胁：
- 基于威胁情报（IOC）：寻找已知的恶意 IP、域名、哈希。
- 基于 TTP（战术、技术和程序）：使用 ATT&CK 框架，推导攻击者可能使用的技术。
- 基于异常行为：分析偏离基线的行为（如半夜管理员登录、异常的网络连接）。

## 2. 威胁狩猎循环（Hunting Loop）

一次完整的威胁狩猎通常遵循以下流程：

1. **提出假设（Hypothesis）**：基于威胁情报或 MITRE ATT&CK 提出假设。例如：“攻击者可能通过计划任务（T1053）在系统上建立了持久化”。
2. **数据收集（Data Collection）**：确定需要查询的数据源（如 Sysmon、Windows Event Log、EDR、网络流量）。
3. **调查与分析（Investigation）**：编写查询语句（如 Splunk SPL、KQL），验证假设，寻找异常。
4. **发现与响应（Response）**：如果发现威胁，转入应急响应流程；如果未发现，记录经验，调整假设。
5. **自动化与改进（Automation）**：将成熟的狩猎规则转化为自动化的 SIEM 告警规则。

## 3. 基于 ATT&CK 的常见狩猎场景

### 场景1：无文件攻击与 PowerShell 滥用
- **假设**：攻击者通过 PowerShell 执行了编码后的恶意命令。
- **数据源**：Sysmon 事件 ID 1（进程创建）、PowerShell 4104（脚本块日志）。
- **狩猎语句（KQL）**：
  ```kql
  event.code: "1" and process.command_line: (*-EncodedCommand* or *-enc*)
  ```

### 场景2：异常横向移动（PsExec / WMI）
- **假设**：攻击者使用 PsExec 在内网横向移动。
- **数据源**：事件 ID 7045（服务安装）、事件 ID 4624（登录类型 3）。
- **狩猎语句（Splunk SPL）**：
  ```spl
  index=windows EventCode=7045 ServiceName="PSEXESVC" OR ImagePath="*PSEXESVC.exe"
  ```

### 场景3：持久化后门排查
- **假设**：攻击者创建了计划任务或修改了注册表 Run 键。
- **数据源**：事件 ID 4698（计划任务创建）、Sysmon 事件 ID 13（注册表修改）。
- **狩猎语句**：
  ```kql
  event.code: "13" and registry.path: *CurrentVersion\\Run*
  ```

## 4. 常用的威胁狩猎工具

| 工具 | 作用 |
|:---|:---|
| **Sysmon** | Windows 终端增强日志（进程、网络、注册表） |
| **Velociraptor** | 终端快速取证与狩猎工具，支持 VQL 查询 |
| **ELK / Splunk** | 日志集中存储与查询平台 |
| **EDR** | 终端检测与响应，具备高级行为分析能力 |
| **MITRE ATT&CK Navigator** | 可视化映射组织的防御覆盖与检测盲区 |

## 5. 面试高频问题

**Q1：威胁狩猎和应急响应的区别是什么？**
A：应急响应是**被动**的，在安全事件发生（如告警触发、系统被黑）后介入，目标是止损和溯源。威胁狩猎是**主动**的，在没有任何告警的情况下，主动假设网络已被入侵，通过分析日志和终端数据，提前发现隐藏的威胁。

**Q2：如果让你对一个企业内网进行一次威胁狩猎，你会怎么做？**
A：首先，基于 ATT&CK 框架提出假设（如“是否存在异常的持久化”）。然后，收集关键数据源（Sysmon、EDR、AD 日志）。接着，编写查询语句排查高风险行为（如异常的 PowerShell 编码执行、异常的 PsExec 服务安装）。最后，对发现的异常进行验证，将有效规则沉淀到 SIEM 中。

**Q3：威胁狩猎中如何处理误报？**
A：首先，分析误报产生的原因（如正常的运维脚本触发了异常规则）。其次，通过白名单或基线（Baseline）排除已知的合法行为。最后，不断优化狩猎规则，提升精确度，避免“告警疲劳”。
