# 灰黑产追踪与威胁情报分析

灰黑产（网络黑灰产业）是网络安全的主要威胁来源。本笔记记录灰黑产的常见业态、威胁情报收集、虚拟货币追踪以及溯源分析思路，主要用于蓝队防守、威胁狩猎和护网溯源反制。

## 1. 灰黑产的基础分类

灰黑产通常分为上中下游三个环节：

- **上游（技术支撑）**：提供漏洞利用工具（EXP）、木马免杀、C2 服务器租赁、钓鱼网站模板、代理IP和VPN、短信轰炸接口等。
- **中游（引流与诈骗）**：通过社工库、钓鱼短信、恶意广告、色情博彩网站进行引流，实施诈骗或窃取数据。
- **下游（资金变现）**：通过“跑分”平台、虚拟货币洗钱、电商虚假交易、游戏币兑换等方式将赃款洗白。

## 2. 威胁情报的收集与分析

### 常见公开情报源（OSINT）
- **威胁情报平台**：微步在线（ThreatBook）、VirusTotal、奇安信威胁情报中心、AlienVault OTX。
- **搜索引擎**：Shodan、Fofa、ZoomEye、Google Hacking。
- **暗网与社交平台**：暗网论坛、Telegram 群组、GitHub 上的恶意项目。
- **区块链浏览器**：Etherscan、Blockchain.com、OKLink（用于追踪虚拟货币）。

### 情报分析方法
- **IOC（入侵指标）匹配**：提取恶意样本中的 IP、域名、URL、Hash（MD5/SHA1/SHA256），在威胁情报平台中查询。
- **TTP（战术、技术和程序）分析**：将攻击者的行为映射到 MITRE ATT&CK 框架，寻找攻击组织的画像。
- **恶意样本分析**：使用沙箱（如微步沙箱、Any.run、Cuckoo）动态运行样本，观察网络请求和释放的文件。

## 3. 虚拟货币追踪基础

虚拟货币是黑产洗钱的主要手段。掌握基础的链上追踪思路，是溯源反制的关键。

### 核心追踪工具
- **区块链浏览器**：
  - BTC：Blockchain.com、BTC.com
  - ETH：Etherscan、OKLink
- **链上分析平台**：Chainalysis、CipherTrace、Elliptic（主要用于合规和执法）。
- **混币器与跨链桥**：Tornado Cash（ETH混币）、跨链桥（用于转移资产逃避追踪）。

### 追踪思路
1. **获取钱包地址**：从恶意样本、钓鱼网站或勒索信中提取攻击者的钱包地址。
2. **查看资金流向**：在区块链浏览器中查询该地址的交易记录，分析资金的来源和去向。
3. **聚类分析**：通过“多输入地址聚类”算法，将同一个攻击者控制的不同钱包地址关联起来。
4. **交易所调证**：如果资金流入中心化交易所（如币安、OKX），可以通过执法部门或平台合规团队调取 KYC 信息，锁定真人。

## 4. 诈骗链路与基础设施分析

在护网或应急响应中，经常会遇到钓鱼网站、诈骗APP等基础设施。分析这些基础设施的关联，有助于溯源攻击者。

- **域名分析**：查看 WHOIS 信息、DNS 解析记录、ICP 备案（可能为虚假或盗用）。
- **IP 与 CDN**：查看 IP 归属地、CDN 厂商，判断攻击者是否使用了云服务隐藏真实 IP。
- **静态资源指纹**：钓鱼网站通常会复用模板，分析其 HTML、JS、CSS 文件的 Hash，可以关联到同一批攻击者。
- **通信特征**：分析恶意 APP 或木马的 C2 通信特征（如特定的 User-Agent、心跳间隔、加密方式）。

## 5. 面试高频问题

**Q1：如何对一个钓鱼网站进行溯源分析？**
A：1. 提取域名和IP，查询Whois和DNS记录。2. 分析网站源码，提取静态资源指纹（JS、CSS的Hash）。3. 查看是否有C2通信或表单提交接口。4. 结合威胁情报平台，查询该IP/域名是否与已知的APT组织或黑产团伙相关联。

**Q2：如果攻击者使用了虚拟货币收款，你如何追踪？**
A：使用区块链浏览器（如Etherscan）查询钱包地址的交易记录，分析资金流向。如果资金进入混币器（如Tornado Cash），追踪难度会大幅增加。如果最终流入中心化交易所，可以尝试通过合规渠道调证，锁定真实身份。

**Q3：威胁情报在蓝队防守中有什么用？**
A：威胁情报可以提供攻击者的 IP、域名、样本 Hash 等 IOC，帮助我们快速封禁和拦截。同时，通过分析攻击者的 TTP（战术、技术和程序），可以优化我们的检测规则和防御策略，实现从“被动响应”到“主动防御”的转变。
