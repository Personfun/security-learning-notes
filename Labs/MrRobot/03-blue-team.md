# 03 蓝队检测视角与防御

从蓝队（安全运营/应急响应）角度，分析 MrRobot 靶场攻击链各阶段会留下的痕迹及防御策略。

## 1. 信息收集阶段

- **检测点**：Web 日志（Apache/Nginx）中出现大量 404 状态码，或者对 `/robots.txt`、`/wp-login.php` 的异常高频访问。
- **防御建议**：
  - 限制 IP 访问频率（WAF 或防火墙层）。
  - 部署 ModSecurity 等 Web 应用防火墙规则，拦截常见的目录扫描工具（如 dirb、gobuster）。

## 2. WordPress 后台爆破阶段

- **检测点**：
  - `/wp-login.php` 出现大量登录失败日志（如 Event ID 或 Web 日志中的 POST 请求）。
  - 短时间内外网对同一用户的密码尝试频率极高。
- **防御建议**：
  - 启用登录失败锁定策略（如 fail2ban 监控 WordPress 日志）。
  - 后台强制使用强密码，并开启双因素认证（2FA）。
  - 隐藏或修改默认的登录入口路径。

## 3. WebShell 与反弹 Shell 阶段

- **检测点**：
  - WordPress 主题文件（如 `404.php`）被异常修改，可通过文件完整性监控（AIDE、Tripwire）发现。
  - 出站流量中出现可疑的 `4444` 端口连接（反弹 Shell 特征）。
- **防御建议**：
  - 严格限制 Web 目录的写入权限，Web 进程用户（`www-data`）不得修改主题模板目录。
  - 在出站防火墙（Egress Firewall）上限制非业务端口的出站连接。
  - 部署 HIDS（如 Wazuh、Osquery），监控敏感文件的修改和异常子进程（如 `bash -i`）。

## 4. 密码破解与 SSH 登录阶段

- **检测点**：
  - 敏感文件（如 `/home/robot/password.raw-md5`）被读取。
  - SSH 日志（`/var/log/auth.log`）中出现异常 IP 的成功登录记录。
- **防御建议**：
  - 不要在服务器家目录下存放明文密码或哈希文件。
  - 定期审计服务器上的密码强度，禁止使用常见弱密码。
  - SSH 限制来源 IP（白名单），或使用密钥登录代替密码登录。

## 5. SUID 提权阶段

- **检测点**：
  - 监控 `find / -perm -4000` 等异常探测命令的执行。
  - 监控 `nmap`、`find`、`vim` 等具备 SUID 权限的程序被非授权用户以异常参数调用。
- **防御建议**：
  - 定期审计 SUID 文件（`find / -perm -4000`），移除不必要的 SUID 权限。
  - 对于 nmap 等工具，禁止设置 SUID 位，或限制其交互模式。

## 总结

MrRobot 靶场的攻击链虽然经典，但在真实防守中，几乎每一步都会留下日志。蓝队需要做好日志集中收集（SIEM），针对上述检测点编写告警规则。
