# 01 靶场搭建

本笔记记录如何从零开始搭建一套 Active Directory 域环境靶场。

## 1. 环境依赖与前置准备

- **虚拟机软件**：VMware Workstation 或 VirtualBox（推荐 VMware）
- **操作系统镜像**：
  - Windows Server 2019/2016（作为域控制器）
  - Windows 10（作为成员机）
  - Kali Linux（作为攻击机）

## 2. 网络配置

为所有虚拟机设置 **仅主机模式 (Host-Only)** 或 **NAT 模式**，确保在同一个虚拟网段内，以便互相通信。

- 规划网段：`10.0.0.0/24`
- 设置静态 IP（推荐）或使用 DHCP。

## 3. 搭建域控制器 (DC)

### 第1步：修改主机名与网络
- 设置主机名为 `DC`。
- 配置静态 IP，例如 `10.0.0.140`，DNS 指向自身 `127.0.0.1`。

### 第2步：安装 AD 域服务
1. 打开「服务器管理器」→「添加角色和功能」。
2. 勾选「Active Directory 域服务」，一路默认下一步安装。
3. 安装完成后，点击旗标进行「将此服务器提升为域控制器」。

### 第3步：创建新林和域
- 选择「添加新林」。
- 根域名设置为 `company.local`（模拟企业域名）。
- 设置目录服务还原模式 (DSRM) 密码。
- 等待安装完成并自动重启。

### 第4步：创建域用户与组
登录域控，打开「Active Directory 用户和计算机」，创建以下测试账户：
- 普通域用户：`test` / `P@ssw0rd`（模拟普通员工，用于初始访问）
- 服务账户：`svc_sql` / `P@ssw0rd`（注册 SPN，用于 Kerberoasting）
- 域管理员：`Administrator` / `P@ssw0rd`（最终目标）

## 4. 配置成员机

### 第1步：修改 DNS
- 将成员机的 DNS 指向域控 IP（如 `10.0.0.140`）。
- 测试连通性：`ping company.local`。

### 第2步：加入域
1. 右键「此电脑」→「属性」→「更改设置」→「更改」。
2. 选择「域」，输入 `company.local`。
3. 输入域管理员凭据，确认加入。
4. 重启成员机。

## 5. 攻击机配置

- 确保 Kali 能访问域环境。
- 配置 DNS 指向域控：修改 `/etc/resolv.conf` 添加 `nameserver 10.0.0.140`。
- 配置主机名映射（可选，但推荐）：修改 `/etc/hosts`，将域名和 IP 对应。

## 6. 环境验证

```bash
# 扫描域控开放端口
nmap -sV -Pn 10.0.0.140

# 预期结果：88 (Kerberos)、389 (LDAP)、445 (SMB)、3389 (RDP) 等
```

## 7. 常见踩坑记录

- **DNS 解析失败**：成员机加入域失败大部分是因为 DNS 没指向域控。一定要先 `ping company.local` 通。
- **时间同步**：Kerberos 认证要求客户端和域控时间差不超过 5 分钟，虚拟机建议开启时间同步。
- **快照**：环境搭建完成后，务必打一个「干净快照」，方便之后反复练习。
