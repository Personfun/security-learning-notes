# 03 蓝队检测视角与防御

Active Directory 域环境是企业内网的核心，也是蓝队防守的重中之重。以下是针对域渗透攻击链的检测点与防御建议。

## 1. 域内信息收集阶段

- **检测点**：
  - 短时间内大量 LDAP 查询（如 `dsquery`、`net group`）。
  - 异常进程发起对 SMB、WMI 的批量扫描。
  - 出现 BloodHound 特有的 LDAP 查询特征。
- **防御建议**：
  - 开启 Windows 高级审计策略，记录 LDAP 查询（Event ID 1644）。
  - 部署 HIDS，监控异常进程（如 `SharpHound`、`AdFind`）的执行。
  - 限制普通域用户对敏感 AD 对象的读取权限。

## 2. Kerberos 攻击阶段（AS-REP Roasting / Kerberoasting）

- **检测点**：
  - **AS-REP Roasting**：事件 ID 4768（Kerberos 身份验证票据请求），如果大量账户的预认证被禁用，会产生大量加密方式为 RC4 (0x17) 的 AS-REQ 请求。
  - **Kerberoasting**：事件 ID 4769（Kerberos 服务票据请求）。短时间内出现大量针对不同 SPN 的 RC4 (0x17) 加密的 TGS 请求。
- **防御建议**：
  - 禁用不必要的“不需要 Kerberos 预认证”选项。
  - 服务账户使用强密码（长且随机，建议 25 位以上），或使用托管服务账户 (gMSA)。
  - 强制使用 AES 加密，禁用 RC4。

## 3. 横向移动阶段（PTH / PsExec / WMI）

- **检测点**：
  - 事件 ID 4624（登录成功），登录类型为 3（网络登录）。
  - 事件 ID 4688（进程创建），监控到 `PSEXESVC.exe`、`WMIC.exe` 或 `cmd.exe /c` 的异常执行。
  - 事件 ID 5140（网络共享访问）中出现 `ADMIN$`、`C$` 的异常连接。
- **防御建议**：
  - 实施分层管理模型（Tier Model），禁止低级别管理员登录高级别资产。
  - 开启 LAPS（本地管理员密码解决方案），确保每台机器的本地密码唯一。
  - 限制域管账户的登录权限，禁止其在普通成员机上登录。

## 4. 域权限提升阶段（DCSync / 黄金票据）

- **检测点**：
  - **DCSync**：事件 ID 4662（目录服务访问），监控非域控机器发起的具有“复制目录更改”权限的请求。
  - **黄金票据**：事件 ID 4624（登录），TGT 的有效期异常长（如 10 年），或使用了异常的加密类型。
- **防御建议**：
  - 严格限制“复制目录更改”权限，仅授予域控本身。
  - 定期重置 KRBTGT 账户密码（至少两次，以清除旧票据）。
  - 将域管账户加入“受保护用户组”（Protected Users Group），防止凭据缓存滥用。

## 总结

域渗透的检测依赖完善的日志收集和 SIEM 规则。蓝队需要针对上述事件 ID 编写告警规则，并对域控实施严格的权限分级和密码策略。
